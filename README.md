# Metformin UHPLC – Analytical Data Review

## Project Overview
Independent portfolio project reviewing published Metformin UHPLC method-validation data from a quality control (QC) perspective.

## Objective
Evaluate reported analytical results, document review decisions, and identify results requiring further investigation.

## Scope of Review
- System suitability: theoretical plates and tailing factor
- Linearity
- Accuracy: recovery
- Precision: %RSD
- Robustness: changes in analytical conditions

## Tools
Microsoft Excel and Google Sheets

## Results
- 19 parameters reviewed
- 15 classified as PASS against the criteria used in this review
- 4 classified as INVESTIGATE because numerical robustness acceptance limits were not documented

## Reviewer Recommendation
Verify the applicability and documentation of acceptance criteria before treating these classifications as formal method-validation approval. Establish suitable robustness limits before assigning final PASS or FAIL decisions.
